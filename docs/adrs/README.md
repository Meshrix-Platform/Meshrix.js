# Architecture Decision Records

This directory indexes implemented and verified long-term architecture
decisions.

An ADR is published here only when its implementation and verification evidence
exist in the repository. Proposed, accepted-but-unimplemented, superseded
planning, audit, and progress material remains in the ignored `docs/plans/` or
`docs/reports/` workspace and is not a current technical authority.

## Status Values

- `Implemented`: current decision with repository implementation and verification evidence.
- `Superseded`: implemented decision replaced by a later numbered ADR.
- `Deprecated`: implemented decision retained only for historical context and no longer recommended.
