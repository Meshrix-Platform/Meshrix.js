Layer assignment heuristics

  1. Upstream services — services/* directories that register into the gateway (model-gateway, skill-hub, file-parser).
  2. Gateway-internal — packages/contracts + foundation (kernel), capabilities (permissions), agents + plugins/model-gateway (adapters). plugins/model-gateway is a Core adapter plugin, not the upstream service itself.
  3. MCP + relay — packages/protocols, packages/server-runtime, apps/server.
  4. External gateways — plugins/external-gateway only; labeled as a supplement for operator-provided Caddy/Nginx/direct endpoints (Meshrix does not ship Nginx/Caddy as product modules).
  5. Client-side plugins / console — plugins/agents/*, plugins/shared-space, plugins/skill-hub, packages/ui-console, apps/console.

Modules and edges are scanned from package manifests and tools/registry/dependency-rules.registry.json. No invented modules. Closest-honest layer wins when a path is ambiguous.
