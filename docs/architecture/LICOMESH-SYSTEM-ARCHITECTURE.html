System Layers

外观层

Layer ID: appearance | Category: appearance | Hydration: optional

  • 控制面板展示网关、工作空间、审批和系统管理界面
  • 只通过应用层或切面层入口调用能力

平台能力

Layer ID: platform-capabilities | Category: core-capability | Hydration: essential

  • 汇聚平台能力、通信服务、协作治理、智能体运行能力和策略管理
  • 承载角色配置、认证管理和能力层装配边界

应用层

Layer ID: application | Category: application | Hydration: optional

  • 网关治理、Agent Workspace、已验证插件资产和通用工具
  • 剥离后失去对应独立应用能力

切面层

Layer ID: aspect | Category: aspect | Hydration: optional

  • 下游客户端、平台应用服务的协议切面
  • 协议适配、请求归一化、能力投影和 route intent

基建层

Layer ID: foundation | Category: foundation | Hydration: essential

  • 安全权限、模块管理、装配能力、数据结构、操作证明、环境兼容性、资源管理和运维基础
  • 平台运行和模块脱水机制的不可剥离底座
