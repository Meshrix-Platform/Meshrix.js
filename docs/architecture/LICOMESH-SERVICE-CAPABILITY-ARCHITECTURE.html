LicoMesh Service Capability Architecture

Authority: packages/contracts/src/modules/manifest.mjs. Projection-only diagram; digest sha256:f9da60236e0d707ba29438e08368c5c20ea2cf7625aa1953829ed4966b455ee4.

Service capability flow from local clients through MCP outlets, operation routing, data substrate, gateways, and operator-configured upstream applications.

Capability Layers

Layer 1 客户端类型

  • Agent Harness
  • LicoMesh Client

Layer 2 MCP 插件能力层

  • Discovery
  • Gateway
  • Verified Plugin Contributions
  • External Protocol Adapters

Layer 3 统一操作路由层

  • Operation Router
  • Policy Router
  • Capability Router

Layer 4 缓存与算法底座层

  • LSM Ingest Pipeline
  • CAS Block Store
  • Merkle DAG Manifests
  • Prefix / Range Index
  • State Commit / Projection

Layer 5 网关层

  • Operation Gateway
  • Service Gateway
  • Block Sync Gateway
  • Secret And Connection Gateway

Layer 6 外部应用

  • Operator-configured upstream APIs
