# libxcb 1.13.1 license source

`libxcb-1.13.1.COPYING` is preserved verbatim from the libxcb 1.13.1 source
COPYING file in the official Debian source archive:

https://sources.debian.org/data/main/libx/libxcb/1.13.1-2/COPYING

The upstream release is listed at:

https://xcb.freedesktop.org/dist/libxcb-1.13.1.tar.gz

This license text accompanies the bundled AlmaLinux `libxcb-1.13.1-1.el8`
runtime. Its RPM declares MIT but does not supply a separate license file.
The upstream version and copyright text must be reviewed when updating this
runtime dependency.
